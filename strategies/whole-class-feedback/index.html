Whole Class Feedback

The strategy, as published

Exactly as it appears on the card

15 📋Whole Class Feedback

Read the set and identify patterns: common strengths, recurring errors, one priority next step. Teach to the gap, not to each paper. Sustainable for teachers; precise for students.

Suggested technology shared display or document tool · Informed by Wiliam; Hattie

Find this under Make feedback more useful

Part of Source & Direction in 03 Feedback, where it sits alongside its neighbouring strategies, the infographic and the thinking for the whole area.

Why you might use it

The problem it may help with

Reading a class set shows you things no single script can, such as the same misconception in eleven books, a strength half the class shares, or one gap that would repay some whole-class teaching. Whole class feedback works from those patterns, so you teach to the gap, not to each paper.

It's sustainable for you and precise for pupils, which is a rare combination in feedback, and thirty individual paragraphs saying the same thing don't serve anyone better than one well-taught response to the pattern.

What it could look like

One way in your classroom

After reading a set of essays without writing in them, you note three recurring issues and one common strength. The next lesson opens with the pattern, which covers what this class does well, the error many of them share, and the one improvement to make now, and pupils then find and fix that issue in their own work.

Try it

A way to begin

Read your next set with a blank sheet beside you and nothing in your pen for the books. Record the patterns only, and build the follow-up lesson from the sheet.

What to notice

Reading what happens

  • Whether pupils can find the general point in their own work, because that's the step where whole class feedback succeeds or fails.
  • How your reading changes when you're looking for patterns rather than composing comments.

Things to think about

Before and while you use it

  • Some pupils will need help connecting the class-level point to their own page, because the two aren't automatically joined up for them, so a quick check on who has found their own example is well worth the two minutes.
  • Whole class feedback replaces some individual marking rather than all of it, and which pieces still need an individual response is a judgement about the work and the class.

Technology second

Where technology fits

A shared display or class document is where the patterns become teachable, with the common strengths and errors laid out once, visible to everyone, and annotated live as the class works through them. Kept in the approved shared space in your setting, the same document becomes a running record of what this class has been taught to fix, which is really useful the next time a pattern threatens to come back.

The wider thinking

Where the evidence sits

This is Wiliam's formative logic applied at class scale, and it reflects Hattie and Timperley's point that feedback informs the teacher as much as the taught, because the set tells you what to do next. The card’s attribution stands as published: Wiliam; Hattie.
